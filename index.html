What are Claude Skills?

Skills are specialized AI agents built on the Anthropic Claude Agent SDK. Each skill is a SKILL.md file that defines an identity, toolset, knowledge base, and trigger patterns — transforming Claude into a domain expert. They connect to live data (Slack, Smartsheets, Google Drive) and are invoked via slash commands like /aio-mastermind.
